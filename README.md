# CodeQuest

A single-page coding adventure for learning JavaScript fundamentals. Explore seven worlds, solve missions, defeat coding bosses, collect hidden bugs, and track progress saved in your browser.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`, then preview it with `npm run preview`.

## Features

- 7 worlds, 21 missions, 63 typed challenges, and 7 boss encounters
- Multiple choice, output prediction, code completion, and debugging challenges
- XP, levels, coins, combos, hints, achievements, daily challenges, and mistake review
- Local, versioned save data with validation and graceful storage fallback
- Persistent light and dark appearance modes
- Responsive layout, keyboard controls, and reduced-motion support

The app has no backend or runtime API dependencies. Browser fonts and icons use local system fallbacks and inline vector components.
